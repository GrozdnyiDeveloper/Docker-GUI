# Примеры образов Docker приложений с GUI
В данном репозитории представлен примеры настроенных образов для развёртывания в Docker приложений с графическим интерфейсом (GUI)

**Архив имеет следующее содержимое:**
- calc-jar-winodw - Образ для запуска в Docker приложения калькулятора, написанного на Java, в контейнере Ubuntu с использованием X11 forwarding для отображения графического интерфейса (GUI)
- xeyes - Образ для запуска в Docker демо приложения со следящими за курсором "глазами" в контейнере Ubuntu с использованием X11 forwarding для отображения графического интерфейса (GUI)
